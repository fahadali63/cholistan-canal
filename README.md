# Cholistan Canal: companion tools

Interactive companion to the paper *Concrete before water: governance gaps behind Pakistan's stalled Cholistan Canal and lessons for desert irrigation megaprojects* (Rafique, Ali & Ali; manuscript prepared for *Water Policy*).

- `index.html`: landing page
- `simulator.html`: ten-daily water balance model used in the paper (IRSA river record, 2014-15 to 2025-26)
- `link-route.html`: route console for the three Federal Flood Commission gauge days in Figure 5

Static HTML, no build step. The ten-daily flow pattern is modelled from IRSA's seasonal totals, not observed.
